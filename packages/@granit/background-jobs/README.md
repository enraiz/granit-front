# @granit/background-jobs

Background job status types -- mirrors Granit.BackgroundJobs .NET contract.

## Installation

```bash
pnpm add @granit/background-jobs
```

## API

### Types

- `BackgroundJobStatus` -- status of a background job (name, state, last execution, next run, etc.)

## Usage

```ts
import type { BackgroundJobStatus } from '@granit/background-jobs';
```
