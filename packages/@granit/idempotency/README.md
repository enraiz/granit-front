# @granit/idempotency

Automatic `Idempotency-Key` header injection on mutation requests (`POST`, `PUT`, `PATCH`, `DELETE`) via `@granit/api-client`.

Part of the [granit-front](../../../README.md) framework.

## Installation

Consumed via `link:` protocol — see the [integration documentation](../../../README.md).
